# 설계 결정

- 기본 엔진은 RealESRGAN_x4plus 하나다. C# IUpscaleEngine, Python BaseEngine을 확장점으로 제공하며 플러그인 검색은 없다.
- BasicSR 1.4.2의 RRDBNet 네트워크 정의를 로컬 포함했다. 전역 registry 의존성을 제거하고 필요한 초기화/레이어 helper만 작성했다. BasicSR 전체·GFPGAN 패키지는 설치하지 않는다. 공식 가중치를 strict=True로 읽는다.
- 타일 입력만 GPU로 보내고 전체 출력은 CPU에서 합성한다. CUDA OOM은 최대 3회 타일을 줄여 재시도한다. 전체 출력용 시스템 RAM이 부족할 수 있으며 모든 크기의 이미지를 보장하지 않는다.
- 입력 방향/포맷 검사를 프리뷰와 추론에서 공유한다. 메모리 내 프리뷰는 최대 4096px, 썸네일은 160px이다.
- 화면에 실현된 썸네일만 로드한다. UI 가상화·재활용, 디코더 동시 실행 3개, LRU 최대 128개. 화면에서 벗어나면 ImageItem의 Bitmap 참조를 해제한다.
- 탐색마다 버전과 취소 토큰을 바꿔 느린 이전 요청이 최신 화면을 덮지 못하게 한다. 폴더 조회 실패 시 이전 폴더와 선택 상태를 복원한다.
- 출력은 동일 폴더의 `.upscaler-<job_id>.tmp`에 쓰고 flush/fsync 후 Windows의 덮어쓰기 금지 rename으로 확정한다. 충돌하면 `_001` 순번을 증가시킨다. 원본/기존 출력은 덮어쓰지 않는다.
- 저장 공간은 비압축 RGBA 크기와 컨테이너 여유분을 기준으로 사전 검사하고 저장 직전 다시 확인한다. 실제 압축 결과보다 보수적으로 거절할 수 있다.
- 설정은 사용자별 LocalAppData에 JSON으로 저장한다. 값 범위와 문법을 검사해 손상 시 기본값으로 복구한다. 다크 테마 자원은 별도 Dictionary로 분리했고 라이트 테마 UI는 선택 범위로 남겼다.
- 작업 모달은 ShowDialog를 사용한다. UI 외 작업·Worker 통신은 비동기이며 작업 요약과 실패 사유는 모달에 표시한다.
- 창 종료는 취소/Worker 정리가 끝날 때까지 지연하고, Dispatcher의 다음 처리 순서에서 실제로 닫는다.
