## 현재 구조와 제약

- .NET 10 WPF / Core / PythonBridge, Python 3.11 + PyTorch 2.5.1 CUDA 12.4 조합.
- 테스트는 tests/Upscaler.Tests 실행형 하네스와 Python unittest. xUnit 프로젝트가 아님.
- 메인 UI와 캐시 변경은 Dispatcher에서, 디스크·디코딩은 백그라운드에서 처리.
- 추론 Worker와 썸네일 디코더는 별도 프로세스이며 수명·취소 처리를 혼합하지 않음.
- 추론 모델은 한 번에 하나만 유지. 모델/장치/정밀도/노이즈 강도 변경 시 다시 로드.
- 프리뷰 원본 크기는 별도 표시, 긴 변 4096 제한. PNG/JPEG 출력, 4배 고정.
- GPU 실기기 검증은 RTX 4090. 다른 GPU의 메모리·속도는 보증하지 않음.
- 단순 자동 렌더는 실제 다중 모니터 DPI 전환 시험을 대체하지 않음.

## 남은 작업과 다음 단계

1. 포맷 후 개발환경을 재생성하고 기존 테스트/실제 실행 확인.
2. 미커밋 가독성 정리와 모델 확장 변경을 검토해 필요 시 커밋·푸시. 이전 푸시 요청은 d7512b9에서 완료됐으며 이후 변경은 아직 로컬 상태.
3. 사용자 실제 이미지로 신규 모델 품질 비교. 작은 자동 테스트의 추론 성공은 품질 평가와 별개.
4. HAT/Real-HAT-GAN 및 sharper는 이후 비교 후보. SUPIR/DiffBIR은 별도 파이프라인, GFPGAN은 후처리 후보이며 미구현.
5. 배포는 사용자 방침대로 작업 완료·테스트 이후. 설치 패키지와 Python 없는 클린 PC 검증은 미완료.
