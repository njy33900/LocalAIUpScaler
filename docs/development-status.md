# 개발 및 검증 상태

검증일: 2026-11-12 (Asia/Seoul). 범위: 프로그램 구현과 이 PC에서의 로컬 검증. 설치 패키지 및 클린 PC 검증은 사용자 요청에 따라 후속 단계로 둡니다.

## 완료한 보완

- 세션별 Worker 상태 분리, 시작/작업 제한시간, 취소 응답 제한시간, 프로세스 종료 확인 후 임시 파일 제거.
- Worker 비정상 종료 이후 자동 재시작, 파일별 실패 후 폴더 작업 계속 진행.
- 타일 경계 및 저장 직전/직후 취소. 이미 파일 확정이 끝났다면 완료로 집계.
- 폴더 탐색 경합 방지, 조회 실패 시 이전 경로 복원, 새로고침 시 선택 유지.
- 썸네일 가상화·재활용, 256개 LRU, 재사용 썸네일 디코더 최대 3개 (프리뷰 디코더 별도). 화면 밖 Bitmap 참조 해제.
- 프리뷰 상한 4096px, 원본 크기 별도 표시, 확대·맞춤·드래그 이동.
- 작은 이미지 확대 버튼 동작 수정, 창 종료 중 재진입 오류 수정.
- 설정 값 검증 및 손상 복구. 기존 타일 설정을 3단계 프리셋으로 마이그레이션.
- 출력 디스크 여유/쓰기 권한 확인, 덮어쓰기 없는 이름 확정, 사용자 원본 보호.
- 프리뷰/추론의 공통 디코더, 포맷 불일치 검사, EXIF 방향, 16비트 회색조 및 알파 정책.
- 환경 복원/검증 스크립트, 고정 패키지 목록, 모델 체크섬, 라이선스 원문·목록, 프로토콜/문제 해결 문서.

- 창 테두리/제목 표시줄과 클라이언트 다크 테마, 드롭다운·스크롤바·확인창 색상 통일.
- 프로그램 이름 강조, 원형 새로고침/F5, 불필요한 상단 버튼 제거, 상태 글자 대비 개선.
- 확대뷰/썸네일 좌우·위아래 전환, 미리보기 상단 Lucide 분할 아이콘, 단일 선택 및 배치 저장. 썸네일은 가로 줄바꿈 격자와 세로 스크롤, 재활용 가상화를 사용. 241개 이미지와 두 창 크기에서 열 배치·선택 유지·스크롤·가상화 검증.
- 중앙 이미지 작업 영역 흰색, 준비 완료 상태는 “엔진 준비됨”으로 간소화.
- 자체 SVG/PNG/ICO 아이콘, 검색 안내·지우기, 탐색 버튼 활성 상태, 확대율과 원본 크기 분리.
- 128 / 256 / 512 타일 선택, 기본 128, 여유 VRAM 권장 추정치 2/3/6 GB, CPU FP32 고정 표시.
- 사용자·세션별 단일 실행과 기존 창/모달 활성화. 별도 프로세스 통신 및 종료 후 재획득 검증.

자동 테스트 총 40개이며 렌더링 8개는 별도입니다. GPU 관련 검증은 이 PC의 RTX 4090에서 실제 CUDA를 사용했습니다. RTX 3060 및 4070 Ti 실기기는 검증하지 않았습니다. OOM/디스크 부족은 시스템을 고갈시키지 않고 오류를 주입해 검사했습니다.

## 검증 범위의 한계

- DPI 렌더는 실제 WPF 뷰를 지정 픽셀 밀도로 그린 결과입니다. 서로 다른 배율의 물리 모니터 사이에서 창을 이동하는 시험은 수행하지 않았습니다.
- 데스크톱 캡처 도구가 시간 초과했고 클릭 좌표를 확보하지 못했습니다. 앱 실행·접근성 조회는 확인했고, 실제 모달의 owner 잠금/복원은 별도 WPF UI 통합 테스트로 확인했습니다. 사용자 마우스로 하는 드래그 앤 드롭·패닝의 수동 인수 검사는 남아 있습니다.
- 환경 준비 스크립트의 검증 모드와 현재 설치 조합을 확인했습니다. Python 미설치 새 PC에서 설치 과정을 재현한 것은 아닙니다.
- 설치 패키지, 새 PC 실행, 실제 네트워크 차단 시험은 `deployment.md`의 후속 범위입니다.

## 썸네일 스크롤 개선

장당 Python 실행을 최대 3개의 상주 썸네일 디코더 풀로 변경했습니다. 진행 중인 중복 요청을 합치고, 화면 밖 요청은 대기 단계에서 취소합니다. 이미 디코딩 중인 이미지는 완료 결과를 제한된 캐시에 보관하되 재활용된 항목에는 할당하지 않습니다. 프리뷰와 썸네일 대기열은 분리되며, 종료 시 디코더를 정리합니다. 오류 파일은 프로토콜을 유지하고, 프로세스 오류/30초 제한시간 초과 시 해당 디코더를 폐기합니다.

로컬 합성 PNG 512×384, 12장: 기존 순차 프로세스 실행 2432 ms, 새 3슬롯 풀 첫 배치 209 ms, 초기화 후 다음 배치 12 ms. 24장 캐시 재조회는 1 ms 미만. 이는 작은 합성 입력에서 실행 오버헤드를 비교한 결과이며 대형 사진·원격 디스크 성능 보장은 아닙니다. 디코더 재사용/캐시/취소/손상 이미지 후 복구를 자동 검사했습니다.

## 결과 위치와 정렬

처리 완료 창에 성공 결과가 있을 때 결과 폴더 열기를 표시합니다. 썸네일은 이름/수정일/파일 크기와 오름차순/내림차순을 지원하고 설정을 저장합니다. 메타데이터 조회는 백그라운드에서 수행하며 선택 보존과 설정 저장을 자동 검증했습니다.
