# 개발 및 검증 상태

검증일: 2026-11-11 (Asia/Seoul). 범위: 프로그램 구현과 이 PC에서의 로컬 검증. 설치 패키지 및 클린 PC 검증은 사용자 요청에 따라 후속 단계로 둡니다.

## 완료한 보완

- 세션별 Worker 상태 분리, 시작/작업 제한시간, 취소 응답 제한시간, 프로세스 종료 확인 후 임시 파일 제거.
- Worker 비정상 종료 이후 자동 재시작, 파일별 실패 후 폴더 작업 계속 진행.
- 타일 경계 및 저장 직전/직후 취소. 이미 파일 확정이 끝났다면 완료로 집계.
- 폴더 탐색 경합 방지, 조회 실패 시 이전 경로 복원, 새로고침 시 선택 유지.
- 썸네일 가상화·재활용, 128개 LRU, 최대 디코더 프로세스 3개. 화면 밖 Bitmap 참조 해제.
- 프리뷰 상한 4096px, 원본 크기 별도 표시, 확대·맞춤·드래그 이동.
- 작은 이미지 확대 버튼 동작 수정, 창 종료 중 재진입 오류 수정.
- 설정 값 검증 및 손상 복구. 잘못된 타일 입력은 실행 전에 거절.
- 출력 디스크 여유/쓰기 권한 확인, 덮어쓰기 없는 이름 확정, 사용자 원본 보호.
- 프리뷰/추론의 공통 디코더, 포맷 불일치 검사, EXIF 방향, 16비트 회색조 및 알파 정책.
- 환경 복원/검증 스크립트, 고정 패키지 목록, 모델 체크섬, 라이선스 원문·목록, 프로토콜/문제 해결 문서.

## 검증 범위의 한계

- DPI 렌더는 실제 WPF 뷰를 지정 픽셀 밀도로 그린 결과입니다. 서로 다른 배율의 물리 모니터 사이에서 창을 이동하는 시험은 수행하지 않았습니다.
- 데스크톱 캡처 도구가 시간 초과했고 클릭 좌표를 확보하지 못했습니다. 앱 실행·접근성 조회는 확인했고, 실제 모달의 owner 잠금/복원은 별도 WPF UI 통합 테스트로 확인했습니다. 사용자 마우스로 하는 드래그 앤 드롭·패닝의 수동 인수 검사는 남아 있습니다.
- 환경 준비 스크립트의 검증 모드와 현재 설치 조합을 확인했습니다. Python 미설치 새 PC에서 설치 과정을 재현한 것은 아닙니다.
- 설치 패키지, 새 PC 실행, 실제 네트워크 차단 시험은 `deployment.md`의 후속 범위입니다.
