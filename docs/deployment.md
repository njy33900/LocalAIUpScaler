# 배포 단계 (사용자 요청에 따라 보류)

현재 완료 범위는 소스 기반 프로그램과 로컬 검증입니다. 설치 패키지를 아직 만들지 않았으며, 개발 환경의 `.venv`를 다른 PC에 그대로 복사하는 방식은 지원하지 않습니다.

후속 배포 작업:
1. WPF 자체 포함 win-x64 publish와 프로젝트 전용 Python 런타임 패키징.
2. 고정된 의존성·공식 모델·체크섬·런타임 라이선스 포함.
3. 개발 PC의 Python/PATH를 사용하지 않는 새 환경에서 설치·실행 확인.
4. 실제 네트워크 차단 상태에서 탐색·CPU/CUDA 추론·취소 확인.
5. 단일 설치 패키지 제작 후 설치/제거 검사.

개발 실행 시 추론 경로에는 모델 자동 다운로드나 원격 호출이 없습니다. 이 코드 검사는 실제 네트워크 차단 테스트를 대체하지 않습니다.
