# 문제 해결

- Worker 준비 실패: `scripts/setup_environment.ps1 -VerifyOnly`로 패키지 버전·모델 체크섬을 확인합니다. 손상된 모델은 자동 덮어쓰지 않습니다. 원인을 확인하고 공식 모델을 다시 준비하세요.
- CUDA 모드 오류: 자동 모드 또는 CPU를 선택할 수 있습니다. CUDA 강제 모드는 자동으로 CPU로 바꾸지 않습니다. 별도 CUDA Toolkit은 개발 실행의 필수 항목이 아니며 사용하는 PyTorch wheel에 맞는 드라이버가 필요합니다.
- 메모리 부족: 작은 타일로 제한 재시도 후 실패를 표시합니다. 큰 결과 이미지는 CPU 메모리도 필요합니다. 입력 크기를 줄이거나 작업을 취소할 수 있습니다.
- 취소가 즉시 끝나지 않음: 현재 타일의 반환 또는 강제 종료 확인을 기다리는 중입니다. 완료 전에 모달을 닫지 않습니다.
- 출력 오류: 폴더 접근 권한, 디스크 여유, 파일명 길이를 확인합니다. 결과는 원본에 덮어쓰지 않습니다.
- 이미지 오류: 확장자와 실제 형식 불일치, 손상 파일, Pillow 보호 한도 초과 등은 해당 파일 실패로 기록합니다.
- 빌드 파일 잠김: 실행 중인 Local AI Upscaler를 닫고 다시 빌드합니다.
- 로그: `%LocalAppData%/LocalAIUpscaler/worker.log`. 5MiB를 넘으면 이전 로그 한 개를 보관합니다. 경로가 포함될 수 있으나 앱은 외부로 전송하지 않습니다.
- 설정 초기화: 앱을 닫고 `%LocalAppData%/LocalAIUpscaler/settings.json`을 별도로 보관한 후 제거하면 다음 실행에서 기본값을 사용합니다.

테스트가 만드는 파일은 `artifacts/tests`와 `artifacts/ui`에 있으며 사용자 원본 폴더를 사용하지 않습니다. UI 통합 테스트는 테스트 창을 일시적으로 표시합니다.
