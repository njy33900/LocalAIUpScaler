# Model weights

`RealESRGAN_x4plus.pth` is intentionally excluded from Git.

Run `../scripts/setup_environment.ps1` from the project to download the official release asset and verify its pinned SHA256 against `SHA256SUMS`. Run the script with `-VerifyOnly` to check an existing local installation without downloading.

The model provenance and license information are recorded in `../docs/third-party-notices.md`.
